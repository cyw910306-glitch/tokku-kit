그림 한 장이면
내 캐릭터 테마 완성

우리 집 강아지, 내가 그린 캐릭터가 말풍선 옆에서 말해요. 친구 말풍선엔 친구 캐릭터, 픽셀 아트도 버튼 하나. 결제도 워터마크도 없어요.

GitHub 소스 보기

그림은 서버로 보내지 않아요. 전부 내 기기 안에서 만들어요. 아이폰 전용.

만들기

지금 보이는 건 데모 강아지 '젤리' 테마예요. 내 그림을 넣으면 바로 바뀌어요.

1. 사진 넣기

png, jpg, webp 다 돼요. 배경이 없는 사진이면 더 예뻐요.

내 캐릭터 (보낸 말풍선, 꼭 필요해요)
친구 캐릭터 (받은 말풍선, 선택)

카카오톡 테마 규격상 받은 말풍선 그림은 친구마다 다르게 할 수 없어요. 테마 하나에 친구 캐릭터 하나라서, 모든 친구의 말풍선에 같은 캐릭터가 나와요.

팁: 아이폰 사진 앱에서 피사체를 길게 누르고 공유 → '이미지 저장'을 고르면 배경 없는 사진이 사진 앱에 저장돼요(iOS 16 이상). 그 사진을 고르세요. PC에서는 복사한 그림을 이 페이지에 붙여 넣어도 돼요.

2. 다듬기

사진 가장자리와 이어진 배경만 지워요. 캐릭터 안쪽은 그대로 남아요. 체크무늬가 보이는 곳이 투명한 부분이에요.

4. 받기

전부 무료예요. 워터마크 없이 바로 받아요.

PC라면: 받은 파일을 PC 카카오톡 '나와의 채팅'에 끌어 놓은 뒤, 아이폰 카카오톡에서 그 파일을 탭하세요.

다 됐어요!

적용한 화면을 캡처해서 인스타에 올려 주세요. 새 템플릿 소식도 인스타에서 알려 드려요.

만든 테마 자랑하고 팔로우하기

설치 방법

  1. 받은 .ktheme 파일을 카카오톡 '나와의 채팅'으로 보내요. 아이폰은 [카카오톡으로 보내기] → 카카오톡 → 나에게 보내기. 그 버튼이 없으면 [파일로 저장] 뒤 파일 앱의 다운로드 폴더에서 파일을 길게 눌러 공유 → 카카오톡 → 나에게 보내기. PC는 PC 카카오톡 나와의 채팅에 끌어 놓아요.
  2. 아이폰 카카오톡 나와의 채팅에서 파일을 탭한 뒤, 공유(또는 열기) 버튼에서 카카오톡을 골라요.
  3. 테마 적용 화면이 뜨면 적용을 눌러요. 안 뜨면 더보기 → 설정 → 화면 → 테마에서 골라요.
  4. 파일 이름 끝이 .zip 으로 바뀌었다면 파일 앱에서 이름 끝을 .ktheme 로 고친 뒤 다시 보내요.

덤

프로젝트를 저장해 두면 카카오톡이 업데이트됐을 때 같은 테마를 다시 만들 수 있어요.

실제로 만들어진 그림 파일로 그린 미리보기예요.

이런 테마가 돼요

01 말풍선 위 캐릭터

올라앉고, 빼꼼하고, 걸쳐요

프사 옆 꼬마, 말풍선 빼꼼, 엎드려 걸치기, 올라앉기까지 네 가지 자리. 글이 길어도 찌그러지지 않게 맞춰 그려요.

02 픽셀

버튼 하나로 픽셀 아트

사진을 도트 캐릭터로 바꿔요. 굵기 3단계, 말풍선까지 픽셀로 맞출 수 있어요.

03 친구 캐릭터

내 말풍선엔 나, 친구 말풍선엔 친구

친구 캐릭터를 넣으면 받은 말풍선에서 친구 캐릭터가 말해요. 커플이면 상대 폰용 테마도 한 번에 만들어요.

템플릿으로 시작해요

고른 뒤에 크기, 테두리, 장식을 하나씩 바꿀 수 있어요. 눌러 보면 만들기에 바로 들어가요.

프사 옆 꼬마 · 말풍선 빼꼼 · 엎드려 걸치기 · 올라앉기 · 픽셀 도트 외 여러 템플릿

무료 · 오픈소스

돈 받지 않아요. 가격표도, 키도, 워터마크도 없어요. 코드는 MIT 라이선스로 공개돼 있어요.

내 그림으로

그림은 내가 넣어요

사이트에는 데모 강아지 말고 다른 캐릭터가 없어요. 내가 그렸거나 쓸 권리가 있는 그림을 넣어 주세요.

내 기기 안에서

서버가 없어요

그림 처리와 테마 만들기는 전부 브라우저 안에서 해요. 그림도 테마 파일도 어디에도 올라가지 않아요.

같이 만들어요

소스가 열려 있어요

버그 제보, 새 템플릿, 캐릭터 팩 형식 개선 모두 환영해요. GitHub에서 만나요.

자주 묻는 질문

어떻게 설치하나요?
  1. 받은 .ktheme 파일을 카카오톡 '나와의 채팅'으로 보내요. 아이폰에서 저장만 했다면 파일 앱의 다운로드 폴더에서 파일을 길게 눌러 공유 → 카카오톡 → 나에게 보내기.
  2. 나와의 채팅에서 파일을 탭한 뒤, 공유(또는 열기) 버튼에서 카카오톡을 골라요.
  3. 테마 적용 화면에서 적용을 누르면 끝이에요.
  4. 이름 끝이 .zip 으로 바뀌었다면 .ktheme 로 고쳐 주세요.
안드로이드에서도 되나요?

아니요. 아이폰(iOS) 카카오톡 전용이에요. 안드로이드는 지원하지 않아요.

정말 무료예요?

네. 비영리 오픈소스라 결제, 키, 워터마크가 전부 없어요. 받은 테마도 처음부터 완성본이에요.

친구마다 다른 캐릭터를 넣을 수 있나요?

아니요. 카카오톡 테마 규격상 받은 말풍선 그림은 하나뿐이라, 테마 하나에 친구 캐릭터 하나예요. 모든 친구의 말풍선에 같은 캐릭터가 나와요.

제 그림이 서버로 가나요?

아니요. 서버가 아예 없어요. 그림 처리와 테마 만들기는 전부 내 브라우저 안에서 해요.

아무 캐릭터나 넣어도 되나요?

내가 저작권을 가졌거나 쓰도록 허락받은 그림만 넣어 주세요. 남의 캐릭터를 쓰면 그 책임은 넣은 사람에게 있어요. 만든 테마는 나 혼자 쓰는 걸 권해요. 팔거나 퍼뜨리지 마세요.

캐릭터 팩이 뭐예요?

pack.json 하나와 그림들을 묶어 캐릭터, 친구 캐릭터, 자리별 그림, 색을 한 번에 채우는 방법이에요. 만드는 법은 GitHub 의 docs/PACKS.md 에 있어요.

카카오톡이 업데이트되면요?

저장한 프로젝트(.json)를 불러와 다시 받으면 새 규격으로 만들어져요. 다만 카카오톡이 사설 테마 방식을 바꾸거나 막을 수도 있어요.
